# Plain writing

Write text that a reader can understand once without decoding the style.

- Use common words. Keep a technical term only when it is needed and explain it once.
- Write complete sentences. Give each sentence one main job.
- Cut filler, vague emphasis, puffery, and unsupported claims.
- Prefer a named person or group as the actor. Do not give human actions to an abstract object when a clearer subject exists.
- Avoid stock contrasts, stacked rhetorical questions, invented compound adjectives, and decorative metaphors.
- Use active voice when it makes responsibility clearer, but do not distort a sentence to avoid every passive construction.
- Use headings, lists, and bold text only when they help navigation.
- Preserve field terms and necessary detail in expert or academic writing.

Revise in two passes. First fix clarity and structure. Then remove every clause that does not add information. Preserve the author's meaning, evidence, uncertainty, and voice.

Do not create a separate revision artifact unless the user asks for one.
