# Plain writing eval

Run this on the finished text before you return it. Answer every check with pass or fail. If any check fails, fix the text and run the checks again. Do not return text that still fails a check.

Each check maps to a numbered rule in `SKILL.md`.

## Words and sentences

1. Rule 1. Is every word the common one rather than the fancy one, with none of the words AI tools overuse, e.g., "delve", "tapestry", "landscape", "robust", "leverage"?
2. Rule 1. Is a repeated word repeated, rather than swapped for a synonym to avoid repeating it?
3. Rule 2. Does every sentence have a subject and a verb, with no fragments?
4. Rule 2. Does each sentence state one thing, with no two ideas stitched together by a colon or a semicolon?
5. Rule 4. Is every technical term either replaced with a plain phrase or said once and explained in plain words?
6. Rule 7. Is every cramped sentence expanded so each point gets its own sentence, and does each item in a list get its own sentence or bullet?

## Punctuation and formatting

7. Rule 3. Are there no em dashes and no en dashes anywhere, including in number ranges, which should use the word "to"?
8. Rule 3. Is every colon introducing a list, with none used to join clauses or to set up a point?
9. Rule 3. Are all quotation marks straight rather than curly?
10. Rule 13. Is every heading in sentence case?
11. Rule 13. Is boldface absent as decoration, e.g., not bolding the first phrase of every bullet?

## Figures of speech and padding

12. Rule 5. Are there no analogies, metaphors, or images, and no "it is not just X, it is Y" pattern?
13. Rule 6. Is every filler phrase cut, e.g., "it is worth noting that"?
14. Rule 6. Is every "-ing" tail that adds fake analysis either cut or replaced with the plain reason, e.g., "stores results, highlighting its value"?
15. Rule 10. Are empty emphasis and puffery words gone, e.g., "really", "matters", "carries weight", "boasts", "a testament to", "pivotal", "renowned"?
16. Rule 11. Is there no three-part series inside a sentence, and no list padded to three for rhythm?
17. Rule 11. Does each point carry one example introduced with "e.g." rather than a stack of examples?

## Structure and honesty

18. Rule 8. Does every inanimate subject take "is" or "are" rather than an action verb it cannot do, apart from a common phrase like "the paper argues"?
19. Rule 9. Is every hyphenated adjective one that people already use, with no coined compound?
20. Rule 12. Is every claim either attributed to a named source or cut, with no "experts say" or "studies show"?
21. Rule 14. Are there no stacked rhetorical questions?
22. Rule 15. Is there no dramatic pivot, meaning a statement set up and then undercut in the next sentence?
23. Rule 16. Is there no setup promising a hidden insight, e.g., "what most people get wrong" or "here is what nobody tells you"?
24. Rule 17. Does the text end on a concrete sentence, a plain takeaway, or the next step, rather than a closing line written to sound deep?

## Paragraphs and precision

25. Rule 18. Is each paragraph about one topic, with the topic stated in its first sentence and no more than about six sentences in all?
26. Rule 19. Is every run of nouns three words or fewer, with any longer stack broken up with "of" or "for"?
27. Rule 20. Does every "this", "it", or "they" point to one clear noun, with the noun repeated wherever the pronoun could point to two?
28. Rule 21. Does every instruction start with the verb and stand in its own sentence, with a comma after any condition that comes first?
29. Rule 22. Is every quantity given as a number where the figure is known, with no vague word such as "most" in its place?

## Process

30. Was the second pass actually run, meaning the text was read again clause by clause and anything that did not earn its place was removed?
31. If the second pass removed or rewrote anything, was the HTML revision artifact built from `assets/revision_template.html`, saved outside the skill folder, and its location given to the user?
32. If the artifact was built, does the saved file contain no remaining `__DATA__` text?
33. Would a reader seeing this text for the first time understand every sentence on one read?
